# Craton

**Africa's 3D geology course.** 23 interactive 3D topics, exam-style practice, rock-history puzzles, a daily challenge with streaks, an Explore Nigeria map and a field kit (Peel & Slice block, Stereonet Bridge, Field Station). Every model, texture and dial is generated by code, so the app is light on data and works offline on budget Android phones once installed.

## Quick start

You only need a static web server. Nothing has to be installed to run the app.

```bash
# Option A: Python (already on most computers)
python3 -m http.server 8080 --directory app
# open http://localhost:8080

# Option B: Node
npm install
npm start            # serves app/ on http://localhost:8080
npm run landing      # serves landing/ on http://localhost:8081
```

Opening `app/index.html` by double-clicking also works for a quick look, but offline install (the service worker) needs a real `http://` or `https://` address.

## How the code works

- **No build step for JavaScript.** React components are written with [htm](https://github.com/developit/htm) tagged templates (`html\`<div>...</div>\``) instead of JSX, so the browser runs the files directly.
- **Shared scope.** Files in `app/js/` are classic `<script>` tags. Top-level `const` and `function` declarations are visible to every later file. **Load order in `index.html` matters.**
- **3D.** Each 3D view uses `createStage()` (in `01-core.js`), which owns a `THREE.WebGLRenderer`, `OrbitControls`, a `ResizeObserver` and full disposal on unmount. It only re-renders when something changes, to save battery.
- **Procedural assets.** Rock textures are painted on `<canvas>` (`paintRock`), and models are built from Three.js geometry. There are no image, `.glb` or texture files.
- **State.** `usePersist(key, initial)` stores state in `localStorage` with the prefix `geoatlas:` (kept for compatibility with earlier builds).
- **Themes.** Colours are CSS variables in `craton.css`; 3D scenes read them through `readTheme()`. "Field" is the high-contrast light theme and "Lab" the dark theme.

## Everyday tasks

| Task | What to do |
|---|---|
| Change styling or add Tailwind classes | Edit the JS/HTML, then `npm run css` (or `npm run css:watch` while working) |
| Add an Atlas model | See "Adding a 3D Atlas model" in `PROMPT.md` |
| Add exam questions | Append to `EXAM_BANK` in `app/js/20-craton.js` |
| Add a Nigeria map place | Append to `NG_PLACES` in `app/js/20-craton.js` |
| Ship an update to installed phones | Change `CACHE = 'craton-v1'` in `app/sw.js` to the next version, and add any new files to `SHELL` |

## Deploy (free)

Upload the **`app/`** folder to any static host:

- **Netlify Drop:** drag `app/` onto app.netlify.com/drop.
- **GitHub Pages:** push the repository and publish the `app/` folder (or move its contents to the root).
- **Cloudflare Pages** or **Vercel:** set the output directory to `app`.

Host `landing/` separately (or at `/`) and point its buttons at the app's address.
